WebTiled — Beta Version

Map editor for Rusted Warfare (.tmx). A Web analog NotTiled.
Opens in the browser. Nothing to download or install.
⚠️ PC only for now — mobile / tablet not supported.


✏️ EDITOR
• Open / save .tmx (base64 + zlib, embedded_png)
• Resize map, layers (add/remove/clear/move/rename), solo, visibility
• Tilesets: add from PNG, delete, zoom, Edit tile, Terrain editor
• Import MiniTNS — 3×5 tile PNG → new tileset + new type
• Undo / Redo, 50 steps

🖌️ TOOLS
• PAN, BRUSH, TERRAIN(TypeNSolid system), Classic Terrain(AutoTiles), ERASE, RECT, FILL, PICK, AUTO, FLOOD
• Brush with weights and shapes

🧩 TYPES  (TypeNSolid system)
• Types with priority
• Solids + 12 edges (sides, outer and inner corners)
• Edges render outside the type (border between types)
• Pick-mode via atlases

🧊 3D VIEW
• Isometric map render
• Height source: generator / Ground
• Color: map texture / palette / grayscale / PNG
• Markers overlay on top of 3D

⌘ MERGE
• Stitch multiple maps via drag-n-drop
• Snap to edges + guide lines
• Overlap allowed (priority by list order)
• Tilesets merged automatically

📍 MARKERS
• Spawns — circle + team number in player colo
• Respools — yellow dots

📷 EXPORT
• 500×500 PNG of the map with markers

⚙️ UI
• English / Russian
• Custom canvas background
• Documentation included
• Hotkeys

🐞 KNOWN LIMITATIONS
• PC only (Windows / Linux / macOS) — no mobile support
• Map autosave is disabled (only settings persist)
• Merge replaces the current map — no undo for it
• Adding a tileset / Import MiniTNS cannot be undone
• Rename / add / remove layer cannot be undone
