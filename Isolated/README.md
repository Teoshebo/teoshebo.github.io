**Map editor for Rusted Warfare · `.tmx` format · `v0.5 Beta`**

**WebTiled** — веб-альтернатива **NotTiled**: редактор карт для **Rusted Warfare** прямо в браузере. Вдохновлён NotTiled, но добавляет то, чего в нём не было: семантические *Types* для автотайла, процедурный генератор heightmap'а, изометрический 3D-вид, склейку карт и референс-картинку для обводки.

## Что нового в 0.5

Этот релиз — в первую очередь про **стабильность и удобство рисования**. Monolithic `app.js` разбит на модули, а автотайлы стали вести себя предсказуемее.

### 🏗 Архитектура
- **Monolithic `app.js` разбит на модули.** Ядро (`app.js`), рисование (`app_paint.js`), ввод (`app_input.js`), файлы (`app_files.js`), UI (`app_ui.js`) и модалки (`app_modals.js`). Состояние по-прежнему в `RW.App`, модули общаются через него.
- **Хоткеи вынесены в `app_input.js`.** Массив `App.pressedKeys` инициализируется в ядре, так что `TypeError` при нажатии `F` / `Shift` больше не возникает.

### 🎨 Classic Autotile
- **Солид больше не затирается.** Если клетка уже помечена как солид (`solidTileId`), `paintClassicCell` никогда не заменяет её краем или пустотой. Это исправило баг, из-за которого одиночный тайл мог исчезнуть.
- **Края рисуются сразу при движении кисти, а не только после отпускания.** `paintClassicCells` обновляет 3×3 область вокруг каждой нарисованной клетки.
- **Умный fallback для отсутствующих масок.** Если точной 4-угловой маски нет, ищется ближайшая, при этом «нехватка солида» штрафуется меньше, чем «лишний солид». Это убирает чёрные артефактные дуги.
- **Пустые клетки остаются пустыми.** Если маска полностью пустая (`-1,-1,-1,-1`), fallback не применяется — клетка остаётся `0`.

### 🧩 Types / TNS
- **Предпросмотр краёв TNS на `Items0` в реальном времени.** При рисовании инструментом `TERRAIN` края обновляются вокруг кисти сразу, а не после `endStroke`. Финальный пересчёт области всё равно выполняется в `finalizeAutotileForStroke`.

### 🧪 «Пирамида» (Concentric Fill)
- **Пустые кольца защищены от автотайла.** В `fillRing` добавлен массив `forcedEmpty`: клетки, которые должны остаться пустыми между кольцами, принудительно чистятся и не залепляются краями.
- **Солидные кольца защищены через `forcedSolid`.** Автотайл не может перезаписать слой солида.

### 🖌 Сервисные заливки
- **Empty Fill (`E+F`)** — временно переключает инструмент в режим заливки **пустотой** (`0`). Удобно для быстрой очистки областей, не меняя активную кисть. Повторное нажатие `F` (или `E+F`) возвращает предыдущий инструмент и кисть.
- **Type Fill (`Shift+F`)** — временно переключает в режим заливки **типом**: клик по тайлу заливает связную область этого же типа, используя его solids. Работает поверх `Ground`, не каскадится (один проход). Повторный `Shift+F` — выход.

### 🖼 UI / UX
- **Референс-картинка** (overlay / underlay + прозрачность). Не сохраняется в `.tmx` и не попадает в `Save Preview`.
- **`Скриншот`** (Save Preview) — экспорт 500×500 без референса.
- **Мобильный топбар** из трёх кнопок: **BRUSH** (выбор инструмента), **MAP** (открыть / сохранить / имя / размер / склейка), **UTILITY** (скриншот / зум / референс). Кнопка **☰** открывает панель LAYERS / BRUSH.

## Быстрый старт

1. Скачай `webtiled.html` — один файл, без сборки, без сервера.
2. Открой в **Chromium-браузере** (Chrome, Edge, Brave, Opera). Firefox / Safari тоже работают, но с оговоркой по референсу ниже.
3. Перетащи `.tmx` на канвас — или нажми **📂 Open** в топбаре.
4. Рисуй. **💾 Save** — записать обратно в `.tmx`.
5. Открывай результат в **Rusted Warfare** или **Tiled**.

Никакой установки и бэкенда. Всё живёт в браузере и в `localStorage` + в файлах, которые ты подкидываешь.

## Возможности

### Types — семантический автотайл

Система типов по приоритету как альтернатива классическому workflow с terrain-масками. Вместо того чтобы тегировать тайлы по визуальному рельефу, ты определяешь **семантические типы** — `Dirt`, `Water`, `Cliff`, `Road` и так далее — а редактор сам разруливает края.

Каждый тип содержит:

- **Имя** + **Priority** + **Цвет**
- **Solids** — список «телесных» тайлов с весами (случайный выбор при рисовании → естественная вариативность)
- **Edges** — 4 стороны + 4 внешних угла (`N, E, S, W, NWo, NEo, SWo, SEo`)
- **Inner** — 4 внутренних угла (`NWi, NEi, SWi, SEi`)

**Как работает.** Рисуешь инструментом **TERRAIN**. Клетка получает случайный solid выбранного типа. При отпускании кисти генератор пересчитывает `Items0`: вокруг клеток типа A, граничащих с типом B (с большим приоритетом), рисуются edge-тайлы B. На границе побеждает больший приоритет. **Начиная с 0.5 края обновляются в реальном времени** — ещё до отпускания кисти.

**Import MiniTNS** — кинь PNG `3×5` (12 edges + 3 solids), и WebTiled соберёт tileset **и** полностью заполненный тип.

### Classic autotile (CLS)

Олдскульный corner-autotile из Tiled — для tileset'ов, которые уже несут terrain-данные. Порядок маски — классический `[TL, TR, BL, BR]`.

**С 0.5:** солиды защищены от перезаписи, а для отсутствующих масок работает умный fallback (без чёрных артефактов).

### FLOOD

Для каждой клетки Ground: если **3+ из 4 ортогональных соседей** — один тип с большим приоритетом, клетка перекрашивается в этот тип. Один проход, без каскада — жми ещё раз, чтобы продолжить. Один undo на нажатие.

### Empty Fill / Type Fill

Два сервисных режима, которые временно меняют поведение заливки, не сбивая основной инструмент.

**Empty Fill (`E+F`)** — заливка **пустотой** (`tileID = 0`). Нажми `E` (зажать), затем `F` — инструмент переключится в `fill` с кистью `[0]`. Клик по карте заливает связную область пустотой. Повторное нажатие `F` (или `E+F` снова) возвращает предыдущий инструмент и кисть.

**Type Fill (`Shift+F`)** — заливка **по типам**. Нажми `Shift+F` — инструмент переключится в `fill`, но с флагом `tempTypeFill`. Клик по тайлу находит его тип через `TypesModel.findBySolid`, определяет связную область этого же типа и перекрашивает её в случайный solid того же типа. Один проход, без каскада. Повторный `Shift+F` — выход.

Оба режима работают в рамках одного undo-транзакции и не затрагивают `Items0` — только `Ground` (или активный слой, если это не Ground).

### Generator

Процедурный heightmap с полноценным пайплайном:

- **fBm / Perlin noise** — `NOISE SCALE`, `OCTAVES`, `LEVELS`, `FLATTEN BOTTOM`, `PLAYABLE %`, `EDGE BIAS`.
- **Симметрия** — `none / mirror X / mirror Y / rotate 180° / quad / diag / anti-diag`, со слайдером силы.
- **Passes** — резка «троп» по границам плато.
- **Импорт PNG** — яркость = высота. Кидаешь heightmap-картинку, получаешь карту.
- **Реки** — S-образные, вручную или авто.
- **Auto Points** — старты и respools по spread / edge margin / height margin.
- **Preview** — живой 256×256 thumbnail heightmap'а с маркерами.
- **Apply to Map** — пишет solids в `Ground`, edges в `Items0`, маппинг уровней → типов по приоритету.

Детерминированно от `SEED`. Шаришь сид — шаришь карту.

### 3D-вид

Изометрический превью. Высота — из heightmap'а генератора или из тайлов Ground; цвет — из живого рендера карты, классической палитры вода/трава/камень, grayscale или из импортированного PNG. Маркеры рисуются сверху, если включены. **DOWNLOAD PNG** — для шаринга.

### Merge — склейка карт

Drag-and-drop композитор для сборки больших карт из маленьких.

- Добавляй любое количество `.tmx` сразу.
- Таскай мышью со снапом к граням.
- Пересечения подсвечиваются красной рамкой; побеждает верхняя строка в списке приоритета.
- Tilesets объединяются по `name + PNG fingerprint`. Совпадают → общий `gid`-пространство. Конфликт имени → `Name_2`, `Name_3`, …
- Слои — union в порядке первой карты, `Items` прибит в конец.

### Референс-картинка

Overlay или underlay PNG/JPG на канвасе для обводки берегов, дорог или спутникового рендера.

- Ползунок **Прозрачность** — `0.00`–`1.00`.
- **Под карту** — уходит под все слои, иначе поверх.
- **Chrome / Edge** запоминает путь между сессиями (File System Access API). **Firefox / Safari** — выбираешь файл каждый раз.
- **Удалить** — очищает референс и забывает путь.

> ⚠️ Референс **не** сохраняется в `.tmx` и **не** попадает в Скриншот. Это вспомогательный слой для авторинга.

### Скриншот (Save Preview)

- Рендерит всю карту в нативном разрешении.
- Добавляет маркеры, если включены.
- Сохраняет пропорции, длинная сторона = **500 px**.
- Центрирует в PNG **500×500**. Пустота — чёрная.

Имя файла: `<имя_карты>_map.png`. Кидай сразу в README, Discord-эмбед или описание пака.

### Маркеры

WebTiled сканирует все слои карты на тайлы с флагами:

- `res_pool` → **respool** (жёлтая точка, `r ≈ 2.5` тайла)
- `team=N` + `unit="commandCenter"` → **старт команды N** (полупрозрачный чёрный круг, `r = 5` тайлов, цифра команды в Arial Black)

Цифры команд циклятся по 10 базовым цветам RW. Размер множится на настройку `Marker size` (0.3×–3.0×).

## Интерфейс

**Топбар** — `📂 Open`, `💾 Save`, `⤢ Size`, `⌘ Merge`, `📷 Скриншот`, `🖼 REF`, `Fit`, `1:1`, zoom readout, `⚙` Настройки, `?` Помощь.

**Левая панель** — `PAN`, `BRUSH`, `TERRAIN`, `CLS`, `ERASE`, `RECT`, `FILL`, `PICK`, `AUTO`, `UNDO`, `REDO`. Иконка `FILL` меняется в режимах `E+F` (🧽) и `Shift+F` (T).

**Правая панель** — `LAYERS` (видимость, порядок, очистка, удаление, solo, переименование) и `BRUSH` (группа тайлов, `+EMPTY`, `FLOOD`, `CLEAR`, size, shape, веса, `CLASSIC TERRAIN`).

**Нижняя панель** — четыре независимых вкладки: `ATLASES`, `TYPES`, `GENERATOR`, `3D`. Сворачивается по `▼`, ресайзится за грэббер.

**Мобила** — топбар сжимается до **BRUSH / MAP / UTILITY**, плюс кнопка **☰** для панели LAYERS / BRUSH.
