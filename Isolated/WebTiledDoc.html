WEBTILED

Map editor for Rusted Warfare · .tmx format · Beta 0.7

1. Overview

WebTiled is a browser-based map editor for Rusted Warfare (.tmx). It is aimed at modders and map authors: paint terrain, use semantic Types, generate heightmaps, preview in 3D, merge maps, add reference images, and use editor-only CAD guides.

Feedback? Contact teoshebo on Discord — discord.com/users/709138215935934525

3. Atlases

In Beta 0.7 atlas navigation uses a dropdown list plus ← / → arrow buttons. Tileset deletion (🗑) is now in the header of the tileset itself.

  • Choose a tileset from the dropdown.
  • Use arrows to switch to the previous/next atlas.
  • Click a tile to replace the brush; Shift+click adds to the brush.
  • + Tileset adds a PNG atlas.
  • Edit, Show IDs, ▶ Terrain work as before.
Smart Deletion: Deleting a tileset automatically removes its tiles from all TNS types and terrain masks. If a type loses some (but not all) tiles, it will be highlighted with a yellow border in the Types panel.

4. Types

Types are semantic autotile definitions: solids, edges and inner corners. Navigation uses a dropdown list plus arrow buttons. The toolbar contains Create TnS, Delete, Import MiniTNS, and Library.

  • Create TnS — create a new type.
  • Delete — delete the selected type.
  • Import MiniTNS — import a 3×5 tile PNG and auto-fill 12 edges + 3 solids.
  • Library — open the type library.

Each type has Name, Priority, Color, Solids with weights, Edges (N/E/S/W + outer corners), and Inner corners.

Auto-Open Atlas: When you select a TNS type, the editor automatically opens the ATLASES tab and navigates to the tileset containing its first solid tile.

Wall Creator (Void)

If a solid has the void property, painting it normally places it on the Ground layer, calculates edges, and then erases the Ground tile. If you hold Shift while painting, the Ground tile is kept, and an ACCEPT button appears to apply the changes later.

5. UTILS menu

The UTILS button on the left toolbar opens a modal window with service tools:

ToolPurpose
ResizeChange map size (W×H)

6. Map Mirror

Map Mirror is available in UTILS. It copies one half of the map onto the other half. The source half is not erased; the copy is overlaid on the destination half.

Modes

  • Left to Right — copy left half onto right half.
  • Right to Left — copy right half onto left half.
  • Top to Bottom — copy top half onto bottom half.
  • Bottom to Top — copy bottom half onto top half.
  • Quad — duplicate the top-left quarter onto all four quarters.

Layers and autotile

  • Layer checkboxes allow mirroring several layers at once.
  • Solid ground tiles are automatically randomized for a natural look.
  • Autotile edges are recalculated automatically after mirroring.
Use Map Mirror deliberately: it writes into the selected layers and changes terrain. Save a copy of the map before large mirror operations.

7. GUIDES

GUIDES is a CAD layer visible only in the editor. It is not saved into .tmx and not included in PNG export.

Enabling

Press the GUIDE button on the left toolbar. The guide layer appears over the map but does not affect game data.

Shapes

  • Lines
  • Rectangles
  • Circles / Ellipses
  • Points

All shapes use a black outline and coordinate labels.

Modes

  • Create — create a new shape.
  • Select — select a shape. Drag its nodes (corners/ends) to resize or move it. Press Delete to remove the selected shape.

Symmetry

When creating shapes, enable checkboxes H-Sym, V-Sym, Diag, or Anti-D to automatically create mirrored copies relative to the map center.

Right panel

The right panel lists all guide shapes and their properties: coordinates, color, and other editable values.

8. Classic autotile (CLS)

Classic corner-autotile based on the tileset terrain mask. Choose tileset + terrain in CLASSIC TERRAIN, then paint. Masks are recalculated for painted cells and neighbours. One undo rolls back the whole stroke.

9. FLOOD

For each Ground cell, check 4 orthogonal neighbours. If 3+ neighbours share the same higher-priority type, repaint the cell to that type. It does not cascade in one pass; press FLOOD again if needed. One undo transaction.

10. Empty Fill / Type Fill

HotkeyModeAction
E + FEmpty FillFlood-fill with empty tiles (0)
Shift + FType FillFlood-fill a connected area of the clicked type with the currently selected TNS type

Shift + F (Type Fill): Flood-fills a connected area of the clicked type with the currently selected TNS type.

These are temporary service modes: repeat the shortcut to return to the previous tool.

11. Generator

Procedural heightmap generator with noise, levels, symmetry, rivers, auto points, PNG import, preview and Apply to Map. Solids are written to the target layer; edges to the edge layer. Level-to-type mapping uses type priority.

12. 3D view

Isometric preview. Height source: generator/PNG or Ground layer. Color mode: map texture, classic palette, grayscale, imported PNG. Use RENDER 3D and DOWNLOAD PNG.

13. Merge

Add several .tmx maps, drag them with mouse, snap to faces, set priority, and merge. Tilesets are merged by name + PNG fingerprint. Overlapping areas use the higher-priority map. The current map is replaced without undo.

14. Settings

Language, canvas background, show markers, marker size. Settings are stored in localStorage.

15. Markers

Starts: team=N + unit="commandCenter". Respools: res_pool. Markers appear in 2D and 3D when enabled.

16. Reference

Reference image is loaded from UTILS → Ref. Set opacity, place under or over the map. It is not saved into .tmx and not included in Save Preview.

17. Layers

Add, move, clear, delete, solo, and rename layers. The layer order follows the map XML. Renaming Ground, Units, or Items can break expected map structure.

18. Tilesets

Add PNG tilesets, edit tile terrain masks and properties, manage terrain types, show IDs. Delete a tileset with 🗑 in the tileset header; the confirmation shows usage count.

19. PNG export

📷 Save Preview renders the map, adds markers if enabled, preserves aspect ratio with long side 500 px, and centers it in a 500×500 black PNG. Reference and GUIDES are not included.

20. Logs

Logs are displayed in the bottom-right corner of the game canvas, overlaid on the map. They show the last 5 actions and do not block painting. When the bottom panel is opened, canvas logs are hidden.

22. Undo / Redo

Painting, flood fill, rect fill, and classic/terrain strokes are undoable. Map merge and some structural operations replace data without undo; save a copy before large changes.

23. Map format

Standard Rusted Warfare .tmx with layers Ground, Items0, Units, Items1, Items2, Items. Tilesets can be embedded. Tile properties define water, respools, starts, and collision flags.

24. Limitations

  • No autosave.
  • Merge replaces the current map without undo.
  • GUIDES and Reference are editor-only and are not saved into the map.
  • Renaming core layers can break expected structure.

25. Saving

Use Ctrl+S or 💾 Save. The file is downloaded as .tmx. It can be opened in Rusted Warfare or Tiled.

WEBTILED

Редактор карт для Rusted Warfare · формат .tmx · Beta 0.7

1. Что это

WebTiled — браузерный редактор карт для Rusted Warfare (.tmx). Рассчитан на моддеров и авторов карт: рисование terrain, семантические Types, процедурный генератор, изометрический 3D-вид, склейка карт, референс-изображение и CAD-направляющие только для редактора.

Вопросы и фидбек? Пиши teoshebo в Discord — discord.com/users/709138215935934525

3. Атласы

В Beta 0.7 навигация по атласам выполнена через выпадающий список и кнопки-стрелки ← / →. Кнопка удаления тайлсета (🗑) перенесена в шапку самого тайлсета.

  • Выбери тайлсет в выпадающем списке.
  • Стрелки переключают на предыдущий/следующий атлас.
  • Клик по тайлу заменяет кисть; Shift+клик добавляет в кисть.
  • + Tileset добавляет PNG-атлас.
  • Edit, Show IDs, ▶ Terrain работают как раньше.
Умное удаление: При удалении тайлсета его тайлы автоматически вычищаются из всех TNS-типов и terrain-масок. Если тип потерял часть тайлов, но не все, он подсвечивается желтой рамкой в панели TYPES.

4. Типы

Types — семантический автотайл: solids, edges и внутренние углы. Навигация — выпадающий список и кнопки-стрелки. На панели доступны Создать TnS, Удалить, Import MiniTNS, Library.

  • Создать TnS — создать новый тип.
  • Удалить — удалить выбранный тип.
  • Import MiniTNS — импорт PNG 3×5 и автозаполнение 12 edges + 3 solids.
  • Library — открыть библиотеку типов.

Каждый тип содержит имя, Priority, цвет, Solids с весами, Edges (N/E/S/W + внешние углы) и Inner corners.

Авто-открытие атласа: При выборе TNS-типа редактор автоматически открывает вкладку ATLASES и переходит к тайлсету, содержащему первый солид этого типа.

Wall Creator (Void)

Если у солида есть свойство void, при обычном рисовании он ставится на слой Ground, рассчитываются края, а затем тайл Ground стирается. Если зажать Shift при рисовании, тайл Ground сохраняется, а вверху появляется кнопка ACCEPT для отложенного применения изменений.

6. Зеркало карты

Зеркало карты находится в UTILS. Инструмент копирует одну половину карты на другую. Оригинал не стирается; копия накладывается поверх второй половины.

Режимы

  • Left to Right — левая половина на правую.
  • Right to Left — правая на левую.
  • Top to Bottom — верхняя на нижнюю.
  • Bottom to Top — нижняя на верхнюю.
  • Quad — верхний левый угол дублируется на все 4 четверти.

Слои и autotile

  • Чекбоксы слоёв позволяют зеркалить сразу несколько слоёв.
  • Тайлы солидов (земли) автоматически перемешиваются для естественного вида.
  • Края autotile пересчитываются автоматически после зеркалирования.
Используй зеркало осознанно: оно записывает данные в выбранные слои и меняет рельеф. Перед крупными операциями сохрани копию карты.

7. GUIDES

GUIDES — CAD-слой, видимый только в редакторе. Он не сохраняется в .tmx и не попадает в PNG-экспорт.

Включение

Нажми кнопку GUIDE на левой панели. Слой направляющих появляется поверх карты, но не влияет на игровые данные.

Фигуры

  • Линии
  • Прямоугольники
  • Круги / эллипсы
  • Точки

Все фигуры имеют чёрную обводку и подписи координат.

Режимы

  • Create — создание фигуры.
  • Select — выбор фигуры. Тяни узлы (углы/концы), чтобы менять размер и положение. Клавиша Delete удаляет выбранную фигуру.

Симметрия

При создании фигур можно включить чекбоксы H-Sym, V-Sym, Diag, Anti-D — тогда автоматически создаются зеркальные копии относительно центра карты.

Правая панель

В правой панели выводится список всех фигур и их свойства: координаты, цвет и другие параметры.

8. Classic autotile (CLS)

Классический corner-autotile по terrain-маске тайлсета. Выбери тайлсет и terrain в CLASSIC TERRAIN, затем рисуй. Маски пересчитываются для нарисованных клеток и соседей. Один Ctrl+Z откатывает весь штрих.

9. FLOOD

Для каждой клетки Ground проверяются 4 ортогональных соседа. Если 3+ соседа относятся к одному типу с большим приоритетом, клетка перекрашивается в этот тип. За один проход каскада нет; при необходимости нажми FLOOD ещё раз. Одна транзакция undo.

10. Empty Fill / Type Fill

ХоткейРежимДействие
E + FEmpty FillЗаливка пустотой (0)
Shift + FType FillЗаливает связную область кликнутого типа текущим выбранным TNS-типом

Shift + F (Type Fill): Заливает связную область кликнутого типа текущим выбранным TNS-типом.

Это временные служебные режимы: повторное нажатие сочетания возвращает предыдущий инструмент.

11. Генератор

Процедурный генератор heightmap: шум, уровни, симметрия, реки, auto points, импорт PNG, превью и Apply to Map. Solids записываются в целевой слой, edges — в слой краёв. Маппинг уровней в типы выполняется по приоритету типов.

12. 3D-вид

Изометрический предпросмотр. Источник высот: генератор/PNG или слой Ground. Режим цвета: текстура карты, классическая палитра, grayscale, импортированный PNG. Кнопки RENDER 3D и DOWNLOAD PNG.

13. Склейка

Добавь несколько .tmx, двигай их мышью, используй снап к граням, задай приоритет и выполни merge. Tilesets объединяются по имени + PNG fingerprint. При пересечении побеждает карта с большим приоритетом. Текущая карта заменяется без undo.

14. Настройки

Язык, фон канваса, показ маркеров, размер маркеров. Настройки хранятся в localStorage.

15. Маркеры

Старты: team=N + unit="commandCenter". Respools: res_pool. Маркеры отображаются в 2D и 3D, если включены в настройках.

16. Референс

Референс-картинка загружается через UTILS → Ref. Настрой прозрачность и положение под/над картой. Референс не сохраняется в .tmx и не попадает в Save Preview.

17. Слои

Добавление, перемещение, очистка, удаление, solo и переименование слоёв. Порядок слоёв соответствует XML карты. Переименование Ground, Units или Items может нарушить ожидаемую структуру карты.

18. Tileset'ы

Добавление PNG-тайлсетов, редактирование terrain-масок и свойств тайлов, управление terrain types, показ ID. Удаление тайлсета — кнопкой 🗑 в шапке тайлсета; подтверждение показывает количество использований.

19. Экспорт PNG

📷 Save Preview рендерит карту, добавляет маркеры при включении, сохраняет пропорции с длинной стороной 500 px и центрирует в PNG 500×500 с чёрным фоном. Референс и GUIDES не включаются.

20. Логи

Логи отображаются в правом нижнем углу игрового полотна поверх карты. Показывают последние 5 действий и не мешают рисованию. При открытии нижней панели логи скрываются.

22. Undo / Redo

Рисование, flood fill, rect fill, classic/terrain-штрихи отменяются. Склейка карт и часть структурных операций заменяют данные без undo; перед крупными изменениями сохрани копию.

23. Формат карты

Стандартный .tmx Rusted Warfare со слоями Ground, Items0, Units, Items1, Items2, Items. Тайлсеты могут быть встроены. Свойства тайлов задают воду, respools, старты и флаги коллизий.

24. Ограничения

  • Автосохранения нет.
  • Склейка заменяет текущую карту без undo.
  • GUIDES и Reference существуют только в редакторе и не сохраняются в карту.
  • Переименование ключевых слоёв может нарушить ожидаемую структуру.

25. Сохранение

Используй Ctrl+S или 💾 Save. Файл скачивается как .tmx и открывается в Rusted Warfare или Tiled.
